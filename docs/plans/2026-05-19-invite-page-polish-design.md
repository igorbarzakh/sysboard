# Invite Page Polish Design

## Goal

Polish the invite acceptance page while keeping it visually close to the current implementation.

## Direction

Use the existing centered card, neutral background, status icon, text stack, and single primary action. Improve the page through tighter vertical rhythm, stronger typography, and a more confident full-width action button. Avoid decorative gradients, new dependencies, and business-logic changes.

## Scope

- Keep the current invite states and text behavior.
- Modify only local invite page styling unless verification exposes a related issue.
- Use existing design tokens and shared `Button`.
- Validate with style linting, build checks, and a browser visual pass.
